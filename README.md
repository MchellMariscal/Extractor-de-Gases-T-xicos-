# Extractor-de-Gases-T-xicos-

Proyecto: Extractor de Gases Tóxicos

Este repositorio contiene el control de versiones del código utilizado en el desarrollo del sistema detector de gases tóxicos.

El proyecto integra sensores MQ7, MQ6 y MQ4, así como un sistema de alertamiento visual, sonoro y eléctrico.

Cada versión incluye mejoras funcionales documentadas en el archivo control_cambios.txt.
